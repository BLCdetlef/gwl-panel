# GWL-Panel – Prototyp 0.1

GRUNDLAGE · WIRKUNG · LEBEN

Erster Tablet-Prototyp für ZUSTAND.

## Inhalt
- 4:3-Layout
- 9 Planetare Grenzen
- Süßwasser als erste aktive Grenze
- eine Unterebene mit mehreren fachlichen Einträgen
- Körperseite mit vereinfachten Organen
- Wirkungspfad, Messwert, Referenzwert, Quelle und Unsicherheit
- bidirektionale Logik Grundlage ↔ Leben

## Hinweis
Die Werte in Version 0.1 sind ausdrücklich Demodaten. Sie dienen nur zum Testen der Bedienlogik.
